공고 데이터는 매일 아침 자동으로 갱신됩니다. 금액은 공고문 표기 기준이며, 투찰 전 나라장터 원문을 다시 확인하세요.

이렇게 찾으면 빠릅니다

주간 요약 리포트와 달리, 이 페이지는 공고 한 건 단위로 찾습니다.

지역 + 업무구분으로 좁히기

예를 들어 경남 + 공사를 고르면 경남 소재 발주기관의 공사 공고만 남습니다. 키워드에 양산을 더하면 양산시·양산교육지원청 등 특정 발주처 공고를 바로 볼 수 있습니다.

마감임박순으로 오늘 할 일 확인

기본 정렬은 마감이 가까운 순입니다. 카드 왼쪽 위 D-day가 2일 이내면 붉게, 6일 이내면 파랗게 표시하니, 오늘 투찰서를 넣어야 할 공고부터 처리할 수 있습니다.

기초금액에서 투찰금액까지 한 번에

카드의 투찰금액 계산을 누르면 공고 기초금액이 계산기에 자동으로 들어갑니다. 사정률과 낙찰하한율만 확인하면 예정가격·투찰금액·입찰보증금까지 바로 나옵니다.

데이터 기준

  • 출처: 공공데이터포털 조달청 나라장터 입찰공고정보서비스(공사·용역·물품) — 매일 1회 자동 수집
  • 기초금액은 공고의 배정예산(부가세 포함) 표기값을 쓰고, 없으면 추정가격에 부가세를 더해 계산합니다.
  • 지역은 발주기관·수요기관명 기준 분류이며, 실제 참가자격의 지역 제한과 다를 수 있습니다.
